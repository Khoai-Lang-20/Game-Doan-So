# 🎯 Game Đoán Số Bí Mật - v1.0 (Cơ Bản)

Phiên bản đầu tiên của trò chơi **Đoán Số Bí Mật (Number Guessing Game)** được viết bằng HTML, CSS và JavaScript thuần.

---

## 🚀 Trải nghiệm ngay phiên bản v1.0
👉 **[Bấm vào đây để chơi v1.0](https://Khoai-Lang-20.github.io/Game-Doan-So/v1.0/)**

---

## ✨ Tính năng phiên bản v1.0
* 🎲 **Số bí mật ngẫu nhiên:** Trình duyệt tự động tạo một số từ **1 đến 100**.
* 💡 **Gợi ý thông minh:** Hệ thống phản hồi ngay lập tức xem số bạn đoán lớn hơn hay nhỏ hơn số bí mật.
* ⌨️ **Hỗ trợ phím Enter:** Cho phép nhấn phím **Enter** trên bàn phím để đoán nhanh mà không cần bấm nút.
* 🔄 **Chơi lại mượt mà:** Nút bắt đầu ván mới tự động tạo số mới mà không cần tải lại trang.
